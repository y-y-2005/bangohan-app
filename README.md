# 🍚 ばんごはん、いる？ (Family Dinner Attendance Sharing App)

家族向け夕食要否共有Webアプリケーションです。

## 🌟 特徴
- **ワンタップ入力**: `食べる` `食べない` `遅れて食べる` `自分で用意` の簡単登録
- **リアルタイム自動同期**: クラウド連携により、家族それぞれのスマホ画面に最新状態が即時反映
- **未回答者の可視化 & リマインド**: リマインド通知機能
- **曜日別デフォルト**: 毎週の定常予定（バイト等）を自動セット
- **PWA対応**: アプリとしてスマホのホーム画面に追加可能

## 🚀 使い方
1. ブラウザでアクセスします。
2. 画面上部で自分の名前（例: 母, 父, 兄, 妹）を選択します。
3. 今日の回答ボタンをタップします。
