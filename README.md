# 🍚 ばんごはん、いる？ (Family Dinner Attendance Sharing App)

家族向け夕食要否共有Webアプリケーションです。

## 🌟 特徴
- **ワンタップ入力**: `食べる` `食べない` `遅れて食べる` `自分で用意` の簡単登録
- **リアルタイム自動同期**: クラウド連携により、家族それぞれのスマホ画面に最新状態が即時反映
- **未回答者の可視化 & リマインド**: リマインド通知機能
- **曜日別デフォルト**: 毎週の定常予定（バイト等）を自動セット
- **PWA対応**: アプリとしてスマホのホーム画面に追加可能

## 🚀 使い方
1. ブラウザでアクセスします。
2. 画面上部で自分の名前（例: 母, 父, 兄, 妹）を選択します。
3. 今日の回答ボタンをタップします。

---

## 🛠 同期がおかしいときの確認手順

データ同期に違和感がある場合は、以下の手順を実施してください。

1. **全端末で2回リロードする**
   - 1回目のリロードで「新 Service Worker」が有効化されて過去のキャッシュが自動全削除されます。
   - 2回目のリロードで最新のスクリプト（`app.v3.js`）が完全に読み込まれます。
   - ⚠️ **重要**: 家族全員の端末で必ず実施してください。1台でも古いコードのまま残っていると、その端末が旧データ形式で全員分のデータを上書きし続けてしまいます。

2. **同期診断ツール（`diag.html`）での確認**
   - [同期診断ツール (diag.html)](https://y-y-2005.github.io/bangohan-app/diag.html) を開いて「診断を実行する」を押します。
   - 表示される JSON データ内に `"ts"` （各回答のタイムスタンプ数値）と `"config_ts"` が含まれていることを確認してください。
